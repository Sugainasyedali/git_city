# Changelog

## Phase 1 · Local foundation

Introduces the fictional repository city, a 3D explorer, selection and sample metadata, a conventional repository directory and the explorer guide. The design documents describe the planned live provider, access boundaries and subsequent milestones. See docs/DEVELOPMENT_PROGRESS.md for release checks and limitations.

## Phase 2 — Vehicle exploration

Added a procedural sports car, fixed-step arcade handling, road collisions, chase and overhead cameras, headlights, speed and direction telemetry, nearby inspection, map teleportation, graphics presets and touch driving controls.
