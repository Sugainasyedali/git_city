# Public roadmap

| Milestone | Deliverable | Exit criterion |
| --- | --- | --- |
| 0 · Foundation design | Comparable-product research, engine and authorization boundaries, design tokens, testing plan | Documents and owner guidance available in source |
| 1 · Demo city | Local interactive city and sample inspector | At least 15 distinct buildings, orbit, zoom, correct selection, responsive fallback and recorded checks |
| 2 · Exploration | Vehicle, collision, chase camera, minimap and touch controls | Drive, stop, reverse, interact and recover on the city streets |
| 3 · GitHub | Server-side authorization, sync, persistent plots and permission-aware cache | Real and fixture providers share contracts; revocation and retry verified |
| 4 · Intelligence | Commit graph, refs, diffs, files, PRs, issues, releases and analytics | Parent relationships, pagination and incomplete results verified |
| 5 · Personal World | Portfolio, headquarters, parks and garage | Public route and private access controls verified |
| 6 · Global World | Opt-in districts, streamed chunks, discovery and bookmarks | Join, visit, navigate and leave without leaking private data |
| 7 · Public release | Performance profiling, accessibility, sharing, deployment and release automation | Production, privacy and end-to-end release checks pass |
| 8 · Extensions | Interiors, history playback, dependency views, missions, organizations and optional AI or multiplayer | Separate product and threat review per feature |

The current delivery includes Phase 2 driving in Repository City. See the development report for verified coverage and unresolved checks.
