# Design system

Use dark surfaces for the frame and a light-on-dark hierarchy. The world occupies the largest available area. Controls adjacent to the map must remain legible over its brightest lights.

| Semantic role | Reference color |
| --- | --- |
| Canvas / secondary background | #080C14 / #0D1420 |
| Surface / elevated surface | #111827 / #1A2333 |
| Border | #2A3548 |
| Primary text / metadata | #E5E7EB / #94A3B8 |
| Primary accent / secondary accent | #38BDF8 / #A78BFA |
| Cyan highlight | #22D3EE |
| Success / warning / danger | #34D399 / #FBBF24 / #F87171 |

Define theme values in the global stylesheet. Use a sans-serif for names and prose, monospace for coordinates and statistics. Pair selection color with a visible focus or selected state. Give icon-only controls accessible names. Allow tab navigation to reach repositories without operating the 3D camera. On narrow screens preserve content and actions through wrapping, scrolling or a compact inspector.
