# Assets and attribution

The city geometry, materials, road layout, facade patterns and page composition are generated or authored in the project. The demo uses fictional repository names and sample values. No imported vehicle, skyline model or third-party photograph is required by the foundation.

Interface icons are supplied by [Lucide](https://lucide.dev/license), distributed under ISC, with upstream attribution details for inherited Feather icons. Preserve the package notices when redistributing. Three.js, React and Next.js carry their own MIT notices in their installed packages. Review font and other asset licenses before introducing external files.
