# Contributing

Read AGENTS.md and the architecture note before modifying the project. Use the lockfile with npm ci, make one coherent change and run the four verification commands in README.md. Changes to selection or geometry should include a regression check based on a stable fixture ID. Include a screenshot and the viewport used for visible changes.

Explain behavior, relevant tests, accessibility effects and remaining limitations in a pull request. Disclose licenses for new assets and dependencies. Use the public roadmap to discuss cross-milestone changes before undertaking them.
